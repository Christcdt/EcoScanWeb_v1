# 🌱 EcoScan — Le tri des déchets simplifié

**EcoScan** est une application web qui facilite le tri des déchets grâce à l'intelligence artificielle. 

Grâce à un modèle de reconnaissance d'images entraîné avec **[Teachable Machine](https://teachablemachine.withgoogle.com/)**, EcoScan permet d'identifier un déchet à partir d'une image et d'indiquer dans quelle poubelle le jeter.

L'objectif : rendre le tri plus simple, plus accessible et encourager les bons gestes pour l'environnement. 

## ✨ Fonctionnalités

-  **Reconnaissance intelligente** — Identification des déchets grâce à un modèle de machine learning entraîné avec Teachable Machine.
-  **Conseils de tri** — Indication de la poubelle adaptée au déchet identifié.
- **Analyse d'images** — Envoi d'une image pour reconnaître un déchet.
-  **Sensibilisation écologique** — Aide à adopter de meilleures habitudes de tri.
- 📱 **Application Android à venir** — Une future version permettra de scanner directement les déchets avec la caméra du smartphone, pour une expérience plus rapide et intuitive.

## 🛠️ Technologies utilisées

- **JavaScript** — Logique et interactions de l'application.
- **Teachable Machine** — Entraînement du modèle de reconnaissance des déchets.
- **Machine Learning** — Classification des images pour identifier les déchets.
- **HTML / CSS** — Interface utilisateur.
- **Vite.js** - Backend


## Installation et lancement

### Prérequis

- [Node.js](https://nodejs.org/) installé sur votre machine.
- npm, généralement installé avec Node.js.
- Git pour cloner le dépôt.

### 1. Cloner le projet

```bash
git clone <URL_DU_DEPOT>
cd EcoScan
```

### 2. Installer les dépendances

```bash
npm install
```

### 3. Lancer le serveur de développement

```bash
npm run dev
```

### 4. Ouvrir l'application

Ouvrez dans votre navigateur l'adresse indiquée dans le terminal, généralement :

```text
http://localhost:5173
```

> **Note :** ces commandes correspondent à un projet utilisant un outil comme Vite. Si le projet utilise une autre configuration, les commandes peuvent être différentes.

##  Prochainement : EcoScan sur Android

EcoScan évoluera bientôt vers une application Android intégrant la caméra du smartphone.

Les fonctionnalités envisagées comprennent :

-  Scanner un déchet directement avec la caméra.
-  Identifier automatiquement le type de déchet.
-  Afficher instantanément les consignes de tri adaptées.
-  Proposer une expérience mobile simple et accessible.

L'objectif est de rendre le tri des déchets encore plus pratique au quotidien, sans avoir besoin de sélectionner manuellement une image dans la galerie.

## 🎯 Objectif du projet

EcoScan est un projet qui associe développement web, intelligence artificielle et sensibilisation environnementale.

Il vise à exploiter la reconnaissance d'images pour résoudre un problème concret du quotidien : **savoir où jeter ses déchets correctement.**
